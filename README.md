# Соседи — обмен вещами и услугами в общежитии

Учебный проект: **«Разработка веб-сервиса для обмена вещами и услугами между студентами общежития»**.

## Актуальность
В общежитии у многих есть вещи, которые нужны пару раз в год (дрель, лестница, инструменты), а соседям
приходится покупать такие же. Многие студенты умеют что-то полезное — починить ноутбук, помочь с учёбой, —
но соседи об этом не знают. Искать нужное в общих чатах неудобно. Сервис собирает всё в одном месте:
можно взять вещь на время, выложить свою или предложить услугу, а сервис напомнит, когда пора вернуть вещь.

## Возможности
- 🔐 Вход в стиле университетского портала: фото кампуса, карточка по центру, переключение языка RU / EN
- 🏠 После входа — выбор общежития (Металлург 1–4, Горняк 1–2, Дом-коммуна, ДСГ корпуса 5 и 6)
- 📦 Каталог вещей и услуг с фильтрами: корпус, категория, статус, поиск, сортировка
- 🤝 Взять вещь на время с выбором даты возврата, откликнуться на услугу
- ➕ Выложить свою вещь или услугу
- ⏰ «Мои обмены»: прогресс срока, напоминания в колокольчике, уведомления браузера
- 👤 Профиль: сколько взял/одолжил, **сколько рублей сэкономил**, рейтинг, достижения, экономия по общежитиям
- ⭐ Оценка соседа звёздами после возврата вещи (рейтинг виден в каталоге)
- 📅 Напоминание о возврате в календарь телефона (.ics с оповещением за день)
- 🌙 Тёмная тема, 🎉 конфетти и достижения
- 📱 Адаптивная вёрстка для телефона

## Вход
Подходит любой логин и пароль: при первом входе аккаунт создаётся автоматически.
Готовый аккаунт с примерами обменов: `demo` / `demo123`.

## Как запустить
- Проще всего: скачайте **`dist/sosedi.html`** — это весь сайт в одном файле, открывается двойным щелчком.
- Или откройте `index.html` из папки проекта.
- Или включите GitHub Pages (Settings → Pages → Branch: `main` / `(root)`).

После правок пересоберите файл: `python3 tools/build_single.py`.

> Это демо-версия: все данные хранятся в `localStorage` браузера, сервера и базы данных нет.

## Структура
```
index.html      — весь сайт: экран входа и приложение на одной странице
app.html        — старая ссылка, перенаправляет на index.html
css/auth.css    — стили входа
css/app.css     — стили приложения
js/data.js      — данные, хранилище, утилиты
js/auth.js      — логика входа
js/app.js       — логика приложения
js/main.js      — запуск: показать вход или приложение
js/i18n.js      — переводы (русский / английский)
tools/          — сборка сайта в один файл
dist/sosedi.html — готовый сайт одним файлом
assets/         — логотип, иконка и фон страницы входа (campus-bg.jpg)
```
